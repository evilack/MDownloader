팟플레이어에서 가져오기연결 시 확인

가져오기를 시작한 뒤 팟플레이어에서 자막 번역을 한 번 실행하세요.

  1. Python 3.11 이상과 Frida를 설치합니다.
  2. 프로젝트의 native/kakao/install.ps1을 실제 확장 ID와 Python 경로로 실행합니다.
  3. 확장 프로그램을 새로고침합니다. 이 도우미는 64비트 팟플레이어 하나를 대상으로 연결합니다.
  4. 팟플레이어를 실행하고 자막이 있는 영상을 엽니다.
  5. 가져오기를 누르고 팟플레이어의 카카오 자막 번역을 실행합니다.
