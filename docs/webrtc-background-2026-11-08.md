# WebRTC 백그라운드 수신과 정상 HLS 복원 — 0.2.30

사용자 확정 요구: 페이지 종료·이동 후에도 WebRTC를 계속 받고, 중단은 정상 완료와 구분한다. G-Velvet 등에서 정상 m3u8도 함께 보여야 한다. 컴퓨터 사용과 푸시는 하지 않는다.

## 원인과 변경

기존 .29는 페이지가 소유한 MediaStream 트랙을 복제해 녹화했다. 탭이 사라지면 해당 연결도 사라지고, 받은 조각을 부분 파일로 저장한 뒤 Chrome의 파일 저장 완료가 전체 수신의 정상 완료처럼 표시됐다. 또한 단독 WebRTC를 감지하면 같은 문서의 HLS 전체를 숨기고, 선언된 HLS 대체 소스 탐색도 건너뛰었다.

- .30의 지원 Ristretto 스트림은 확장 오프스크린 문서가 별도 WebSocket/PeerConnection/MediaRecorder를 소유한다. 사이트가 실제 송신한 연결 정보와 현재 트랙에 묶인 세션만 사용한다. 원본 페이지의 화질·트랙·연결을 바꾸지 않는다.
- 인증 정보는 페이지 메모리에서 오프스크린으로 한 번만 전달하며 작업·세션 저장소나 로그에 기록하지 않는다. 패키지 설정의 정확한 WSS 호스트를 검증한다. 원격 SDK를 실행하거나 인증값을 추측하지 않는다. 초기 관측 정보가 없으면 페이지 새로고침 안내를 표시한다.
- 오프스크린이 자체 녹화 조각을 직접 OPFS에 기록한다. 원본 탭의 종료·이동 이벤트는 이 작업을 종료하지 않는다. 기존 현재까지 저장·중지 및 저장·취소와 저장 폴더를 재사용한다.
- 사용자의 중지 및 저장만 정상 수신 종료로 취급한다. 연결 실패·장시간 미디어 정지 등은 받은 부분을 보존하고 중단·부분 저장 상태로 표시한다. 부분 파일의 저장 성공과 방송 수신의 정상 완료를 구분한다. 이전 버전의 recording+partial 작업도 이 구분에 포함한다.
- WebRTC의 존재만으로 HLS를 숨기는 조건을 제거했다. 실제 광고·미리보기 역할과 blurred 대체 프로필은 제외하지만 정상 HLS URL은 보존한다. 미분류 연결 점검 재생목록이 대체 HLS 탐색을 막지 않도록 했다.

## 검증 상태

독립 수신기 프로토콜/종료/취소/버퍼/실패 테스트, 원본 페이지 종료 알림 뒤 계속 쓰기·현재까지 저장, 중단 상태와 정상 중지 구분, 인증 정보 미저장 및 WSS 허용 호스트 검사를 포함한다. 실제 G-Velvet은 WebRTC 1920×1080을 재생했으며 사이트 선언 HLS 마스터에서 HTTP 200과 정상 #EXTM3U를 확인했다.

전체 Node 테스트 241개 통과. 프로젝트 검사는 JavaScript 173개, JSON 16개, 상대 import 447개, 로컬 참조 98개, 보존 파일 73개, 실패 0이다. 현지화 10개 언어 × 378개 메시지, 누락 참조 0이다. 페이지 정책 일치와 diff 공백 검사도 통과했다. 별도 읽기 전용 리뷰에서 Important 이상의 확정 문제는 보고되지 않았다.

사용자 새로고침 후 Chrome에서 .30 적용을 확인했다. 사용자는 WebRTC와 정상 m3u8이 함께 표시된다고 확인했다. 브라우저 API로 실제 WebRTC 작업의 수신 상태와 수신량을 읽었으며, 한 작업은 active 상태에서 8,683,755바이트를 기록하고 이후 사용자의 requested 중지로 22,456,146바이트를 저장하는 단계까지 진행했다. 이로써 실제 확장 Origin에서 독립 서버 연결과 미디어 수신이 작동함을 확인했다.

**사용자가 직접 원본 탭 종료를 시험하고 WebRTC와 m3u8 모두 다운로드가 유지된다고 확인했다.** 자동화가 직접 탭을 닫아 측정한 종료 전후 바이트 시계열은 아니며, 탭 종료 후 지속은 사용자 실측 확인으로 기록한다. 비정상 연결 종료의 중단·부분 저장 상태와 페이지 종료 알림 뒤 계속 쓰기는 회귀 테스트로 검증했다. 실제 연결 장애를 일부러 발생시켜 실행 중 다운로드를 끊지는 않았다.

브라우저 URL 정책이 확장 관리/팝업 프로토콜 접근을 거부하여 해당 버튼은 사용자가 조작했다. 검증은 Windows 컴퓨터 사용 없이 브라우저 API와 사용자 확인으로 진행했다. .29까지의 기록은 당시의 페이지 의존 구현에 관한 이력이다.
