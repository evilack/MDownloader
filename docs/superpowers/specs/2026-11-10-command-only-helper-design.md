# 명령 실행 전용 도우미

사용자가 리뷰 결과를 근거로 직접 구현을 요청했다. 앱의 판단·처리 흐름은 확장에 두고 기능 변경을 공통 도우미 재설치 사유로 만들지 않는다.

## 책임

- 확장 실행 관리자: 준비→인식 순서, 대체 입력, 구간 큐, 모델 카탈로그·다운로드 파일 선택, 언어 선택, 자막 시간 변환·직렬화, 결과 이름·충돌 재시도, 작업 상태와 재시도 수명.
- 네이티브 실행 어댑터: 인증·경로·메시지·자원 한도 검증, 요청한 파일 I/O·HTTPS 전송·오디오 디코딩·한 구간 인식, 프로세스 소유·취소·종료, 실행 결과 반환. 자막 작업 상태와 후속 작업을 결정하지 않는다.
- 공통 설치 어댑터: 등록된 확장이 전달한 제한된 상대 경로 매니페스트를 검증·추출하고 안정된 OS별 bootstrap 진입점을 실행한다. 내부 모듈 이름/개수는 알지 않는다.

## 적용

기존 화면/상위 자막 API는 확장 내부 어댑터로 유지하되 네이티브에는 개별 실행 명령만 전달한다. 단순 이름 변경이나 기존 Python 워크플로 실행으로 우회하지 않는다. 기존 안전한 프로세스 소유 코드는 재사용한다. 현재 미커밋 기능 소스가 작업 폴더에 있으므로 해당 폴더에서 범위를 제한해 수정한다. 기존 변경을 커밋/이동/초기화하지 않는다.

기존 본체에는 고정 파일 목록 계약이 있어 최초 계약 전환 업데이트가 필요하다. 이후 내부 파일 추가·분할을 동일 본체로 설치하는 회귀 검증을 필수로 둔다. 설치된 사용자 도우미와 활성 작업은 자동 변경하지 않는다.

## 인수

실제 확장→프리미티브 호출 순서, 준비 실패 시 앱의 조치, 저장 충돌 이름, 구간 병합·시간 변환, 취소 후 미실행, 네이티브의 워크플로 요청 거절, 추가 파일 패키지 허용/경로 탈출 거절을 검증한다. 소스·번들·설치본·실제 엔진 검증을 구분하여 보고한다.
