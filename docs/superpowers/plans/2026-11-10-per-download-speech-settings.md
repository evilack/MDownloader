# 다운로드별 음성 자막 설정

사용자 요청: 다운로드 옵션의 음성 자막 생성 항목을 번역 위로 이동하고, 기본 설정 / 생성 / 미생성 / 사용자 지정 설정을 제공한다. 사용자 지정 설정은 해당 다운로드에만 적용하며, 다운로드된 모델이 있는 엔진과 실제 보유 모델만 선택할 수 있다.

## 구현

- 실제 다운로드 옵션에서 재사용하는 `caption-download-option.js`에 엔진·모델·음성 언어·SRT/VTT 설정을 모은다.
- 도우미와 엔진별 보유 모델을 조회한다. 조회 중에는 진행 문구를 표시하고, 생성 요청은 확인이 완료된 뒤 제출한다. 창을 닫거나 다른 다운로드를 열면 이전 조회 결과를 무시한다.
- 글로벌 옵션을 저장하지 않고 `captionOverride: custom` 및 명시적인 `captionSettings`를 전달한다. 작업 등록 시 검증한 설정과 출력 형식 배열을 복사해 보관한다.
- 하단을 `현재 설정 : 1080p, subs(3), gensub, Trans(ko)` 형태로 표시한다. `gensub`는 음성 자막 생성이 선택되고 도우미·엔진·보유 모델·출력 형식이 준비된 경우에만 표시한다.
- 모든 사용자 지정 입력은 제출 중 잠그며, 취소 후 다시 열 때 다운로드별 선택을 복원한다.

## 검토 범위

사용자의 테스트 금지 지시를 유지한다. 소스와 호출 경로를 정적으로 검토하며 테스트·문법 검사·브라우저 검증·도우미 실행·모델 다운로드·빌드는 실행하지 않는다. 실제 동작 검증은 수행하지 않은 상태로 보고한다.
