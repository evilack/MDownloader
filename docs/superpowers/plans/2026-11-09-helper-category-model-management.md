# Helper category and speech model management implementation plan

User-approved behavior: a dedicated Helper category owns install, removal and diagnostics. Dependent folder/voice controls offer a confirmation popup which navigates to Helper. Missing/deleted helper resets storage to browser default location and voice engine None, with a removal notice. None hides voice details. A single model selector lists owned/missing models with Download/Delete buttons; downloads have a cancellable progress modal; removal requires confirmation. Model and language fields are vertically stacked. User explicitly prohibits running tests.

Interfaces and ownership:
- `lib/helper-availability.js` exposes StartHelperAvailability, RefreshHelperAvailability, SubscribeHelperAvailability, CurrentHelperAvailability, MarkHelperRemoved, ResetHelperDependentSettings. It checks the common native host, confirms loss across multiple observations, persists safe defaults, and dispatches availability/removal events. `options-helper.js` binds Helper installation, repair, removal and diagnostic controls.
- `settings-dialog.js` owns accessible native confirmation/notice dialogs. `options-helper-navigation.js` gates dependent features and navigates via settings-navigate. `settings-ui.js` owns the helper category and location radio guard.
- `local-captions-settings.js` adds engine none (default), disables captions while none, and preserves None on macOS. `local-captions-ui.js` owns the speech form, conditional details, all-model selector and actual button availability. `caption-model-dialog.js` owns progress/cancel and completion/error UI.
- Runtime requests captionPrepareModel / captionCancelModel take engine, model, operationId (32 lowercase hex); captionDeleteModel takes engine/model. Native model-state events include operationId. Cancellation is only completed when the original download settles; deletion validates dedicated model paths and rejects busy models.

Implementation sequence: implement native model lifecycle and helper lifecycle in independent file scopes; integrate navigation and settings markup; connect model UI requests/events and storage updates; integrate worker-side availability rechecks; refresh bundled installer source payloads if required for new native actions. Read-only static review covers None round-trips, delete/cancel races, retained caption host after helper loss, navigation cancellation, installed/missing button states and safe model paths. Do not execute tests, live probes or installers; do not claim runtime acceptance.

Source implementation completed: Helper category and navigation gates, None defaults and automatic loss resets, removal notices with persisted acknowledgment, vertical model/language fields, unified model ownership controls, cancellable progress dialogs and deletion confirmation. Model cancellation kills the owned download subprocess and waits for prepare completion; deleting a saved active model disables that saved default immediately. Static review corrected pending-model selection loss and decoupled deletion readiness from FFmpeg availability.

Helper protocol version 3 and native probe modelManagement capability require a one-time Helper update for previous installations. Repair reconnects the cached caption native port only when no caption jobs are active. The source payload JSON files were regenerated using the three existing data-bundle writers so actual future installers include new host/model actions; no installer or PKG was executed. Tests, syntax/check runners, live native probes, browser verification and real model downloads/removals were not run per user instruction. Runtime behavior remains unverified.
