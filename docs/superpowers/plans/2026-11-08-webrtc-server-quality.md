# WebRTC 서버 화질 선택

사용자 요구: 서버가 실제 제공하는 화질을 선택하고 기존 Shift+다운로드 화질 창과 다운로드 관리자를 사용한다. 컴퓨터 사용은 금지하며 브라우저 API로 검증한다.

실제 관측: 기존 Ristretto 시그널링의 getStreamInfoReply.profiles는 240p(426×240), 480p(720×480), source(720×960)를 제공한다. 160p_blurred는 제외한다. changeQuality의 서버 확정 응답은 changeQualityStatus이다.

1. document_start MAIN 관측기로 기존 소켓과 PeerConnection의 SDP 식별자를 연결한다. 인증 정보/SDP/소켓 주소는 확장 메시지나 저장소에 보내지 않는다.
2. 정확한 수신 트랙에 연결된 서버 프로필만 기존 화질 창에 제공한다. 프로필이 없으면 오류를 표시하고 가짜 선택지는 만들지 않는다.
3. 기존 세션으로 화질 변경을 요청하고 서버 성공 응답 및 실제 영상 크기를 확인한다. 녹화 기간에만 선택을 유지하고 취소/실패/종료 때 원래 플레이어 제어로 돌린다.
4. 기존 MediaRecorder와 다운로드 관리자 경로를 재사용한다. HLS 선택 동작은 유지한다.
5. 프로토콜/트랙 연결/기존 Shift UI/취소 경합 회귀 테스트, 전체 검사 및 실제 서버 수신 크기 전환을 검증한다. 설치된 확장 UI 검증과 개발용 브라우저 검증을 구별한다.
