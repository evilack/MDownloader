# 임시 저장 기반 음성 자막 출력과 인식 프리셋

## 사용자 확정 사항

- 다운로드한 영상은 임시 저장소에서 음성 인식·번역·자막 삽입을 완료한 다음 최종 파일만 저장 폴더로 복사한다. 처리 전 원본 영상을 먼저 복사하지 않는다.
- 출력 형식에 `컨테이너에 포함`을 추가한다. 컨테이너 포함은 기본 활성화하고, SRT/VTT는 필요할 때 함께 선택할 수 있다.
- 별도 자막 취소 버튼은 제거한다. 다운로드의 기존 취소 버튼으로 수신·음성 인식·번역·자막 삽입·저장 단계를 취소한다.
- Faster-Whisper와 whisper.cpp의 프리셋 및 개별 설정을 옵션에 추가한다. 개별 설정을 이름과 함께 사용자 프리셋으로 저장·삭제할 수 있다. 다운로드 창에는 개별 인식 파라미터 없이 프리셋만 제공한다.
- 테스트는 실행하지 않는다.

## 구현

새 작업은 `captionPipeline: staged`를 사용한다. 기존 저장 후 별도 인식 경로와 구분하며, 네이티브 인식 완료 이벤트가 목적지에 조기 저장하지 못하도록 한다. 직접 파일 다운로드도 음성 자막을 사용하면 오프스크린 임시 저장 경로를 거친다.

공통 최종 출력 경로는 기존 자막 번역을 다운로드 후로 지연하고, 임시 영상 또는 미리 준비한 오디오를 인식한 뒤 생성 자막을 읽어 번역한다. 기존 자막과 생성·번역 자막을 한 번에 컨테이너에 삽입한다. SRT/VTT도 임시 파일로 완성한 후 최종 영상과 같은 폴더에 저장한다. 인식·번역·삽입 실패 시 원본 영상으로 대체 저장하지 않는다. 완료 목록과 알림은 최종 출력 완료 상태를 따른다.

인식 설정은 스레드 수, beam size, best-of, 온도, 구간 내 이전 문장 참고를 공통 제공한다. Faster-Whisper는 장치·정밀도·VAD, whisper.cpp는 GPU 사용을 추가한다. `빠르게 / 균형 / 정확도 우선` 기본 프리셋과 엔진별 사용자 프리셋을 제공한다. 사용자 프리셋 변경은 Web Locks로 직렬화하며 저장 시작 시 엔진·수치·이름을 고정한다. 다운로드 작업은 선택한 프리셋 ID와 인식 설정을 복사·동결하여 이후 프리셋 변경의 영향을 받지 않는다.

실행 직전 네이티브 `recognitionOptionsVersion >= 1`을 확인한다. 이전 네이티브가 새 설정을 무시하지 못하도록 도우미 버전 7 및 업데이트 경로를 함께 적용한다. 현재 개별 옵션은 엔진의 실제 지원 범위에 맞춰 제한한다. whisper.cpp decoder 수는 최대 8이고 구간 문맥은 기존 30초 오디오 파일 안에 적용한다.

## 검토와 한계

소스·호출 경로·취소 신호·프리셋 저장 동시성을 정적으로 검토한다. 네이티브 엔진 옵션은 공식 upstream 소스에 대조한다. 테스트·문법 검사·브라우저 검증·실제 설치·인식·모델 다운로드·번역 API 호출은 실행하지 않는다. 설치용 소스 페이로드 데이터만 재생성한다. 기존 pywhispercpp 1.2.0 바인딩의 GPU 제어 미지원은 명시적인 오류로 처리하며 지원되는 것처럼 보고하지 않는다.
