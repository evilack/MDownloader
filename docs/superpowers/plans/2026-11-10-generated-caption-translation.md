# 음성으로 생성한 자막의 번역과 공통 언어 코드 UI

## 원인과 요구사항

다운로드 옵션은 선택한 기존 자막만 번역 원본으로 검사하고, 음성 인식 완료 경로는 자막을 저장한 뒤 종료했다. 기존 자막을 모두 해제하고 한국어 음성 자막 생성과 영어 번역을 선택한 경우, 생성된 자막을 번역 원본으로 사용해야 한다.

언어 코드 직접 입력 항목은 모든 번역 언어 콤보박스에서 `사용자 지정 (예: ko)`로 표시하고, 옵션과 다운로드 창의 언어 선택 UI를 공통으로 사용한다.

## 구현 범위

- 기존 자막 미선택 + 음성 자막 생성 가능 상태를 번역 원본으로 인정한다. 생성 자막을 사용하는 안내와 `Trans(en)` 요약을 표시한다. 생성도 기존 자막도 없는 요청은 계속 거절한다.
- 해당 다운로드에 `translation.generated`를 기록한다. 인식이 끝나면 원본 SRT/VTT를 먼저 저장하고 기존 번역 어댑터로 번역한다. 시간과 문장 수를 유지하고, 번역본은 `영상명.generated.en.srt` / `.vtt`로 별도 저장한다.
- 번역 실패 시 원본을 보존하고 오류·재시도·취소 상태를 제공한다. 인증값은 기존 신뢰 컨텍스트 설정에서 읽으며 작업에 저장하지 않는다.
- 브라우저 저장 폴더에서는 도우미가 번역본을 같은 폴더에 저장하도록 청크 전달 API를 추가한다. 크기·순서·언어 코드·형식을 검증하고 임시 파일을 완료 후 확정한다. 폴더 직접 선택에서는 승인된 폴더 핸들을 사용한다.
- 설치된 이전 도우미와 새 저장 API를 구별하도록 도우미 버전을 6으로 올리고 자막 기능 capability를 추가한다. 설치 패키지에 최신 소스를 포함한다.
- `language-code-control.js`의 공통 선택 UI를 옵션과 다운로드 창에서 사용한다. 음성 언어 목록도 공통 언어 표기 함수를 사용하되 엔진이 지원하는 언어만 제공한다.

## 검토 범위

사용자 지시대로 테스트·구문 검사·브라우저 검증·설치·실제 다운로드·음성 인식·외부 번역 호출은 실행하지 않는다. 소스 검토와 설치 페이로드 데이터 생성만 수행한다.
