# Windows helper removal

Add a Windows-only remove button beside download-location settings and a current-user Windows Installed Apps entry. Both use the same safe native uninstaller. Confirmation cancellation must change nothing. Confirmed removal deletes only known helper files, native folder bindings/lifecycle records and this helper's registry registrations. It must preserve media/subtitle files, even if such files happen to be placed inside the helper directory. Reset extension downloadFolder/pickedDownloadFolder only after a verified removal receipt.

The native host schedules a temporary uninstaller worker, acknowledges it, then exits so its own files can be removed. The worker validates the exact current-user helper root, refuses reparse roots/foreign registrations, removes an explicit filename allowlist, and removes the directory only when empty. Windows Installed Apps launches the same entry with its own confirmation. Installation registers the entry and a random installation identity. Native ping records the identity and Chrome client location; a shipped lifecycle callback page authenticates the removal identity, checks the host is absent, resets settings and consumes the receipt. This supports Windows removal while Chrome was closed without editing Chrome databases.
